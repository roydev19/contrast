# CR
The data provided gives an insight into the different types of interfaces that are running in the SAP PI/PO systems for different departments and scenarios. Here are some insights:

1.  Different departments like 'MKT' are utilizing the SAP PI/PO system.
2.  Different software components like 'SC\_SPEED of adityabirla' are used for running these interfaces.
3.  Various interface modes such as 'Asynchronous' are used.
4.  Different types of sender adapters like 'IDOC' and receivers adapters like 'REST' and 'SOAP' are utilized.
5.  All the receiver components like 'BusServ\_SPEED' and 'BusService\_OSPD' have a description of their corresponding scenarios like 'DI PGI Cancel SPEED', 'DI Create SPEED', 'DI Update SPEED' etc.
6.  The go-live status of these interfaces is 'Completed' indicating that they are all up and running.
7.  Different types of IDOCs/BAPIs like 'DESADV.DELVRY06.ZDELVRY06', 'INVOIC.INVOIC02.ZINVOIC02' etc., are used in these interfaces.
8.  Most interfaces have a Disaster Recovery (DR) measure in place as indicated by 'Y'.
9.  Frequency of data transfer varies with each interface; however, some interfaces don't have this information available.
10.  The interfaces appear to be utilizing different types of communication channels as seen in 'Receiver\_CC' and 'Sender\_CC'.
11.  The interfaces are designed for both 'CR' (Change Request) and other applications.
12.  The target system to which the interfaces connect are running on various IP addresses and have different namespaces.

Please note that it is apparent not all fields are populated or used within this dataset and the frequency of data transfer isn't always specified.
